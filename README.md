# Simulador de cuotas en React

![Simulador de cuotas](screenshot.png)

## Descripción

El simulador de cuotas es una aplicación web que permite calcular el valor de las cuotas de un préstamo.

## Características

- Cálculo del valor de las cuotas
- Cálculo del valor total del préstamo
- Cálculo del valor de los intereses
- Cálculo del valor del capital
- Cálculo del valor del saldo
- Cálculo del valor de la tasa
